# Sistema Reconect

## Objetivos
Realizar um sistema que conecte cada jovem com algum ancião da igreja, ter facil gerencia de jovens, e emissão de alertas e avisos

## Usuários do sistema
- Administrador
- Líder
- usuário
- Recepcionista(Posterior);


## Problemas Identificado
- Falta de organização do pessoal
- Gestão de avisos ainda em papel/mensagem
- Demora para repasse de infdormações

## Requisitos Funcionais

- RF01 - Criar Usuário
- RF02 - Criar Grupo
- RF03 - Edita Usuário
- RF04 - Edita Grupo
- RF05 - Deleta Usuário
- RF06 - Deleta Grupo
- RF07 - Consulta Usuário
- RF08 - Consulta Grupo
- RF09 - Emite Avisos
- RF10 - Cancela Avisos
- RF11 - Edita Avisos
- RF12 - Atuibui usuário à Grupo

## Requisitos Não Funcionais

- RNF01 - Sistema Exige Autenticação
- RNF02 - Sistema Deve Funcionar Em Modo Mobile
- RNF03 - Dados Com Bakcup Periódico
- RNF04 - Apenas Usuário autorizados podem ter acesso a determinadas funções


## Regras de Negócio

- Somente Admin Deleta outro usuário/grupo;
- Um usuário pode estar em mais de um grupo;
- Lideres Criam, Editam e Atruibuem usuário;
